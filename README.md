## Publish with GitHub Pages

1. Log in to [GitHub](https://github.com/) and create a **Public** repository named `brandon-portfolio` (or any other repository name).
2. Upload **`index.html` and `styles.css`** to the root of the repository, then commit the changes. (Do not upload only the ZIP file.)
3. Open **Settings → Pages** for the repository.
4. Under **Build and deployment**, select **Deploy from a branch**, then select **main** and **/(root)**, and click **Save**.
5. Once GitHub finishes deployment, your website will be at `https://YOUR-USERNAME.github.io/brandon-portfolio/`, replacing `YOUR-USERNAME` with your actual GitHub username and using your actual repository name.
6. Test the live URL on your phone and computer, and confirm all section links, email, and LinkedIn links work.
7. Submit **both** your public repository URL (`https://github.com/YOUR-USERNAME/brandon-portfolio`) and the live website URL in the assignment submission.
